## CURRENT ANIMATION DIRECTION — MOHO DEBUT 14

Today's cutout experiment did **not** prove that 2D cutout animation is impossible. It showed that inventing a custom image-processing/animation system with ChatGPT and Codex is likely to consume excessive time and create fragile technical problems.

Dedicated 2D animation software was therefore investigated. Moho Pro and Moho Debut were considered:

- The user does not want to pay approximately `$399` for Moho Pro.
- Moho Debut 14 costs approximately `$59.99` and appears likely to provide the basic tools this project needs.
- The official 30-day Moho trial was downloaded.
- At startup, the user deliberately chose **MOHO DEBUT** as the trial edition.

All trial work must use a Debut-compatible workflow so it remains editable with the inexpensive product after trial expiration. Verify capability before depending on a feature; do not casually introduce Pro-only features.

Moho is intended for simple, controlled movement with enough intermediate motion to avoid ugly jerking while preserving the original drawings. Likely techniques include carefully separated artwork, appropriate layer structure, correct pivots/bones, and purpose-drawn replacement art where rigid movement cannot preserve anatomy.

Permanent animation rules:

- Preserve originals and keep verified backups before destructive preparation.
- Never overwrite the only copy of source artwork.
- Use true alpha transparency; never bake checkerboard transparency into an asset.
- Keep registration, scale, and attachment points consistent.
- Prevent frame-to-frame pulsing or drift.
- Respect anatomical shoulder, elbow, wrist, and hand movement.
- Use replacement drawings when mechanical movement would distort the art.
- Approve a small preview before producing a full set or integrating it into the game.
